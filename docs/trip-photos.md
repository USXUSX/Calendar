# 日別の写真参照

旅行単位のApple「写真」の通常アルバム名は、既存の **`yyyy-mm-dd_場所`**（旅行開始日）の命名規則に合わせる。
Tripの任意項目`photoAlbumName`に、そのアルバム名を完全一致で指定する。
Tripの表示名は変更しない。未設定のTripでは写真リンクを表示しない。
各日の「写真」は端末の `CAL Trip Photos` ショートカットへ、そのアルバム名と
旅程日付をJSONテキストで渡す。写真は端末で検索・プレビューし、CAL/Frameには保存・送信しない。
写真アプリのアルバム画面へ直接移動するリンクではない。

## 端末で一度設定する

iPhone/iPad/Macの「ショートカット」で `CAL Trip Photos` を作成する。
同じApple Accountのショートカット同期を利用できるが、写真アクセスは各端末で許可する。

1. 「入力から辞書を取得」に「ショートカットの入力」を渡す。
2. 辞書の `album` の値を取得して変数「アルバム名」に設定する。
3. 同じ辞書の `date` の値を取得する（`YYYY-MM-DD`）。「入力から日付を取得」で日付へ変換して変数「対象日」に設定する。
4. 「写真を検索」に**すべての条件**を設定する。
   - 「アルバム」「次と等しい」＝変数「アルバム名」。値欄は固定アルバムを選ばず、長押し等で変数を指定する。
   - 「撮影日」「次の日付と同じ」＝変数「対象日」。時刻範囲や今日の日付にはしない。
   - 撮影日の古い順、件数制限なし。
5. 検索結果がある場合は「クイックルック」で表示する。0件の場合は「写真が見つかりません。アルバム名と撮影日を確認してください」と通知する。

端末・OSによってアクション表記は異なる。写真を保存、アルバムへ追加、削除するアクションは不要。
リンク初回実行時に、ショートカット起動と写真アクセスを許可する。
アルバムを改名した場合は`photoAlbumName`も合わせる。Trip名を変えてもアルバム名は変わらない。同名アルバムを複数作らない。
撮影日は端末上の写真の日付を使うため、時差のある旅行では表示日付の一致を確認する。

## 接続契約と確認

URLはAppleの `shortcuts://run-shortcut`、`name=CAL Trip Photos`、`input=text`。
`text` はURLエンコードされた `{"album":"2027-05-14_合成の場所","date":"2027-05-14"}`。

コード・ブラウザのValidationではリンクの引数まで確認する。
**ショートカット本体の端末設定と、実写真がアルバム＋撮影日で正しく絞られることは実機での確認が必要**。
別日を含む通常アルバムで2日分のリンクを開き、それぞれ該当日の写真だけが表示されることを確認する。
設定前のリンクからは「ショートカットが見つからない」旨が表示される。
