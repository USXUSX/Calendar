# 写真アプリでのアルバム・日付検索

旅行単位のApple「写真」の通常アルバム名は、既存の **`yyyy-mm-dd_場所`**（旅行開始日）の命名規則に合わせる。
Tripの任意項目`photoAlbumName`に、そのアルバム名を完全一致で指定する。
Trip表示名は変更しない。未設定のTripでは一覧・日別とも写真リンクを表示しない。

- Trip一覧の「写真」はアルバム名だけを渡して、写真アプリでその名前を検索する。
- 各日の「写真」はアルバム名と`YYYY-MM-DD`形式の日付を渡して、写真アプリで日付を検索する。
- 日付検索は旅行アルバム外の写真も対象に含む。

共通の`CAL Trip Photos`ショートカット1つを使う。検索結果の「写真／コレクション」の
初期タブは写真アプリ側の状態に従う。アルバム検索ではコレクションから対象を選ぶ。
直接アルバム画面へのリンクではない。検索解析が未完了の端末では結果が欠ける場合がある。
写真はCAL/Frameに保存・送信しない。

## 端末で一度設定する

1. 「入力から辞書を取得」に「ショートカットの入力」を渡す。
2. 辞書の`album`の値を取得して変数「アルバム名」に設定する。
3. 同じ辞書の`date`の値を取得して変数「対象日」に設定する。日付型へ変換せず文字列のまま使う。
4. If「対象日に値がある」なら、写真アプリ用の「検索」に「対象日」を渡す。
5. 「その他の場合」では写真アプリ用の「検索」に「アルバム名」を渡す。

写真を取得する「写真を検索」やQuick Lookは使わない。「検索」は写真アプリの検索結果へ移動するアクション。
iPhone/iPad/Mac間でショートカットを同期できるが、アクションの利用可否や権限は端末で確認する。
アルバムを改名した場合は`photoAlbumName`も合わせる。Trip名を変えてもアルバム名は変わらない。

## 接続契約と確認

URLはAppleの`shortcuts://run-shortcut`、`name=CAL Trip Photos`、`input=text`。
`text`はURLエンコードしたJSON文字列。

- 一覧の`photo_url`: `{"album":"2027-05-14_合成の場所"}`。`date`キーを含めない。
- 各Dayの`photo_url`: `{"album":"2027-05-14_合成の場所","date":"2027-05-14"}`。

CALの一覧取得は既存どおり読み取りのみ。FrameはURLをそのままリンクにする。
コード・ブラウザのValidationでは一覧に日付がないこと、日別には該当日があることまで確認する。
端末ではCALのリンクから実行する。入力のないショートカット編集画面の実行ボタンでは確認できない。
一覧からアルバム名、日別から2日分の日付で写真アプリに移動できるかを確認する。

Apple公式資料: [URLからショートカットを実行](https://support.apple.com/guide/shortcuts/apd624386f42/ios)
